# Recap celebration animation

`recap-celebration.json` is generated from the free LottieFiles animation at
`https://assets2.lottiefiles.com/packages/lf20_u4yrau.json`.

- Source reference: `https://lottiefiles.com/1370-confetti`
- License: Lottie Simple License
- Local changes: vector colors are mapped to the Food Link mint/gold palette; the original top and side bursts are retained to frame the report card.
- Regeneration: run `node scripts/fetch-recap-celebration.mjs` from the repository root.

The downloaded source is pinned by SHA-256 in the regeneration script so an upstream replacement cannot silently enter the app.
