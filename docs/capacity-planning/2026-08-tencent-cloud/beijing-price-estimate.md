## 采购和谈判要点

- TKE 启用跨可用区节点池和 HPA：10× 从 3 台 4C8G 起步；20× 从 3 台 8C16G 起步，预留自动扩容到 6 台的配额。
- PostgreSQL 要求自动备份、PITR、跨可用区切换；上线前根据连接数和慢查询决定是否增加只读实例。
- Redis 当前数据量很小，重点是多可用区和连接数，不必机械采购大内存。
- CKafka 当前流量小，但生产级专业版最低档固定成本较高，要求商务提供低吞吐生产套餐或组合折扣。
- CDN 只承载图片、静态资源和可缓存下载；宣传流量不确定，优先谈流量包和突发阶梯价。
- COS 开启版本控制、生命周期与备份策略；表中未计读写请求及回源流量。
- 免费但必须配置：VPC/子网/安全组、CAM 最小权限、DNSPod 基础解析、云监控告警、数据库与 Redis 备份策略。
