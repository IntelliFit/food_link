# 食探校园食堂任务认领与群运营

食探采集项目组 | 2026年10月16日 | 配套采集规范 v1.0

本流程适用于付费采集与学生自发贡献。付费任务按事先明确的范围交付，学生可提供零散线索。任务状态与资料是否上线分开管理，验收材料不代表确认每条菜品的现实真实性，也不依赖营养分析是否成功。

## 任务如何拆分

菜单建档以“一个窗口、一次采集、明确餐段或时间范围”为基本单位。整层任务先拆成窗口清单；窗口数量未知时先做目录摸排，不承诺一次采齐整层。补图和纠错分别建任务，避免菜单任务无限扩张。

同一个窗口允许后续价格更新、缺页补采和实物补图。认领的是本次工作，不是永久占有该窗口。志愿者的有效新材料不因别人认领而拒收。

## 认领与提交流程

1. 管理员发布任务卡，写明地点、范围、截止时间、交付要求。付费任务必须同时说明报酬、结算时点及补采规则。
2. 采集者回复“认领＋任务编号＋预计完成时间”。管理员确认负责人并更新任务表后，认领生效；仅群内接龙不视为自动抢占成功。
3. 首次参与先完成一个窗口样本。管理员只核对分组、可读性和缺项；样本通过再扩大领取量。
4. 按规范拍摄，现场检查。没有菜单、拒绝拍摄、窗口未营业或菜单未拍全时如实报告，不凭空补齐。
5. 按任务卡指定位置交原图，附地点、日期、材料类型及缺项说明。提交成功应获得回执或管理员确认，不以群消息已发出替代归档确认。
6. 管理员给出“合格、部分有效待补、无法使用”的具体结论。反馈必须指向照片或缺项，只补缺的部分；系统识别失败不直接算采集者失败。
7. 付费任务按已确认条款结算；志愿贡献登记来源。后续发现错误可补充新证据，不覆盖原始材料和贡献记录。

## 任务状态

待认领 → 已认领 → 已提交 → 合格／待补采 → 已结算（仅付费）。取消、延期、重新开放由管理员记录原因与时间。资料处理另记“待处理、待说明、已入库”，不能把处理排队误写成采集不合格。

已认领任务到期未完成，先联系负责人确认；无法继续时释放任务。报酬争议按领取前的任务卡核对，不能事后追加未约定要求。

## 活动开始前的准备

确认管理员、任务表与原图接收位置，先发布少量试采任务。收集两类耗时：现场采集与离场后的整理纠错。若合格素材仍频繁需要人工抄录，先调整算法或任务范围，不马上扩大招募。

群公告可直接使用后两页或独立文本文件。新素材处理入口通过验收前，不在公告中承诺小程序已能自动拆菜单、自动配图或自动结算。当前用管理员确认认领和按任务卡交资料即可。

## 付费采集群公告

欢迎加入食探校园食堂采集群。

我们希望把各食堂“在哪里、卖什么、怎么计价”的资料采清楚。采集不要求买菜，不要求每道菜单独拍，也不要求逐条手抄菜单。

【如何认领】

请查看群内任务卡，回复“认领＋任务编号＋预计完成时间”，由管理员确认后开始。每张任务卡会写明地点、采集范围、截止时间、提交方式、报酬及结算条件；这些内容未确认前，请不要先做付费任务。首次参与先完成一个窗口样本，再领取更多任务。

【怎么采】

一个窗口一组。先拍招牌与柜台定位，再近拍完整菜单和计价说明；电子屏轮播要分页面拍。菜名、价格、单位及套餐小字都要能放大看清。菜单过长可以分段，相邻照片留一两行重叠。

菜单建档不强制成品图。领取实物补图任务时，可以多道同框，但需要标签或现场确认的名称对应。没有标签、不确定名称，就如实说明，不能靠外观猜。套餐总价、配料价和单菜价要分清。

【怎么交】

按任务卡指定方式提交原图，每个窗口分开，附学校、食堂、楼层、窗口、拍摄日期和缺项说明。不要发截图代替原图，也不要把菜单、环境照强行填成一道菜。提交后确认管理员已收到并归档。

【验收与结算】

按事先约定的范围、可读性和归属清楚程度验收，不按照片数量凑数。需要补采会指出具体缺项，不要求整批重拍。菜单本身没写清的信息、软件识别失败，不自动算拍摄不合格。报酬与结算按任务卡执行，重复材料不重复计同一项工作量。

临时无法完成请及时告知管理员，申请延期或释放任务。不要进入后厨、移动食品或影响供餐；避开人脸、工牌和支付信息。详细拍法与正反例见《食探校园食堂采集规范与照片判例》。

## 学生自发采集群公告

欢迎加入食探校园食堂共建群。

我们想和大家一起补齐校园食堂资料，让同学更容易找到窗口、了解菜单和价格。顺路拍一张清楚菜单、补一张实物图、纠正一次价格，都有帮助。不要求买饭，不要求逐道拍菜，也不要求先申请成为代理。

【随手贡献】

尽量注明学校、食堂、楼层、窗口和拍摄日期。菜单照片请保留菜名、价格、单位和套餐说明，发原图，不用截图。照片请按窗口分组，不把不同窗口混在一起。不知道的就写不确定。

【想系统采一个窗口】

可回复管理员认领任务：“认领＋任务编号＋预计完成时间”，确认后再开始。零散补充不需要认领；别人正在采的窗口，也欢迎提供不同时间的新菜单、缺少的照片或纠错信息。

【实物怎么拍】

可以一张拍多道。标签尽量与实物同框；没有标签但确认过菜名，可以说明“哪张图、哪一排、哪个位置是什么菜”。无法确认的先作为窗口实物资料，不要猜名称、份量或价格。只拍到菜单也完全可以贡献。

【怎么提交和纠错】

请联系管理员确认本次资料接收方式，原图附简短说明一起交。发现旧资料有误，告诉我们是哪条信息、现在应改为什么、何时发现；有菜单照片就一起提供。旧照片请注明实际拍摄日期，不当作最新价格。

本群以自愿共建为主，不默认承诺报酬。若有付费任务，会单独写清条件。请尊重现场秩序，不影响工作人员和同学用餐，尽量不拍人脸、工牌及支付信息。

具体拍法见《食探校园食堂采集规范与照片判例》。欢迎先发一个窗口的小样，一起把方法磨顺，再逐步扩大覆盖。
