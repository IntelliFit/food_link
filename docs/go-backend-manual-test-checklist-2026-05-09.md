# Go 后端迁移手工测试清单

日期：2026-05-09
适用分支：`backend-refactor-sync-migrate-tencent`
目标：在继续开发新功能前，确认 Go 后端迁移版本的小程序主链路可用。

## 0. 测试规则

- 测试时 server、worker、前端 watch 必须同时运行。
- P0 问题出现后先停止继续测后续链路，优先记录和修复。
- 每个问题至少记录：页面、操作步骤、实际结果、期望结果、是否可复现、截图或日志、账号、时间。
- 需要观察 worker 的功能，不能只看前端提交成功；必须确认任务最终完成或失败原因可见。
- 涉及支付、积分、会员、记录写入、删除等操作时，尽量使用测试账号，避免污染核心生产账号。
