# 可复用食物成分数据源调研（2026-08-12）

## 结论先行

有可借用的数据源，而且 **Foodlink 当前最适合先导入的是台湾卫生福利部食品药物管理署（TFDA）的“食品营养成分资料集”**：它是政府官方开放数据，中文（繁体）名称和华人常见食物覆盖较好，提供 ZIP/API、每 100 克营养、俗名、英文名、废弃率、样本数和标准差，并明确采用“政府资料开放授权条款第 1 版”。项目内也已经有针对这一来源的审核清单与幂等导入器，可以先用它补黄豆、黑豆和常用豆制品，再逐批扩展。

USDA FoodData Central（FDC）适合作为第二来源，许可最宽松、接口和批量下载最成熟，但主体是英文和美国食物口径。尤其不能把 USDA 的 `Beans, black` 自动翻译成中文“黑豆”：前者通常是黑龟豆等普通菜豆（*Phaseolus vulgaris*），中文日常“黑豆/黑大豆”通常指黑种皮大豆（*Glycine max*）。黄豆也必须匹配 `soybean`，不能匹配 `yellow bean`。USDA 数据可补广度与微量营养，但中英文映射必须人工审核或以学名、食物状态和口径做严格门禁。

中国大陆“中国食物成分表”最贴近大陆中文名称和饮食语境，也明确收录黄豆与黑豆；但其官方查询平台声明，未经中国疾控中心营养与健康所允许，不得用于商业目的。因此在 Foodlink 取得书面授权前，只能用于人工查阅、差异核验和候选优先级，不应批量抓取或直接导入商业产品数据库。

FAO/INFOODS 更适合做国际标准、字段定义、食物编码和专项/区域数据的补充来源，不是一个许可证统一、可直接整库灌入的“中国常用食物库”。其不同表格和区域数据库需逐个核验许可、版本、单位与分析口径。

## 1. TFDA：当前项目首选

### 官方性、许可和获取

台湾政府资料开放平台把“食品营养成分资料集”的提供机关列为卫生福利部食品药物管理署，许可列为“政府资料开放授权条款-第 1 版”，计费方式为免费；页面同时给出 JSON、CSV、XML 资源和符合 OAS 的 API，并说明数据量较大、以 ZIP 压缩。字段包含食品分类、资料类别、整合编号、样品名称、俗名、样品英文名称、内容物描述、废弃率、分析项、含量单位、每 100 克含量、样本数、标准差、每单位含量和每单位重量。[TFDA 官方开放数据页](https://data.gov.tw/dataset/8543)；[政府资料开放授权条款第 1 版](https://data.gov.tw/license)

该许可允许在满足条款的情况下重制、散布、公开传输、编辑和开发产品或服务。落库时仍应保存 `source`、数据集 URL、版本/下载日期、原始整合编号和许可名称，产品或说明页保留来源标示；不要把官方归因抹掉，也不要暗示 TFDA 为 Foodlink 背书。

### 黄豆、黑豆与中文覆盖

项目已经为官方 TFDA 数据建立人工审核清单，其中明确包含：

- `黄豆（干货，生重）`，审核别名包括“干黄豆”“生黄豆”“大豆（干货）”；
- `黑豆（黑大豆，干货，生重）`，审核别名包括“青仁黑豆”“生黑大豆”“干黑大豆”；
- 黑豆浆、黑豆粉、烘烤黑豆、黄豆粉等常见加工形态。

这说明黄豆、黑豆不但“网上有”，而且项目已具备从官方数据导入的直接路径。现有实现位于 `backend/cmd/tfda-food-import`，审核清单位于 `backend/data/tfda_food_import_review.json`；它会记录源数据哈希、审计报告、许可与来源，并对危险别名做阻断。正式执行写库前仍须按项目数据库迁移/目标库确认流程进行，本调研不执行导入。

### 限制

- 繁体名称需要繁简转换，但转换后仍要人工检查地域词和一词多物。
- 同名食物必须区分生/熟、干货/泡发、带糖/无糖、可食部/整物重。
- 不建议一次全量自动激活；应以“常用且当前未命中”为优先队列，批次导入并保留回滚依据。

## 2. USDA FoodData Central：开放度最高，但中文映射风险高

### 许可、API 和下载

USDA 官方明确说明 FDC 数据属于公有领域、无版权，并以 CC0 1.0 发布；使用无需许可，但请求列明 FoodData Central 为数据来源。API 提供食物搜索和食物详情接口，需要 data.gov API key，默认限制为每 IP 每小时 1,000 次请求，超限返回 429。[USDA FDC API Guide（含许可与速率限制）](https://fdc.nal.usda.gov/api-guide/)

官方同时提供 JSON 和 CSV 批量下载，可分别下载 Foundation Foods、SR Legacy、FNDDS、Branded Foods，也可下载全量数据。Foundation 以分析数据为主；SR Legacy 是截至 2018 年的历史标准参考；FNDDS 面向美国膳食调查食物；Branded 来自商品标签且规模很大。不同 data type 的来源和更新频率并不相同，不能混成同一质量层级。[USDA 官方下载页](https://fdc.nal.usda.gov/download-datasets/)；[USDA Data Type Documentation](https://fdc.nal.usda.gov/data-documentation/)

Foodlink 仓库已经存在 `backend/scripts/import_usda_fooddata.py`，默认优先 Foundation + SR Legacy，并映射能量、蛋白质、碳水、脂肪、纤维、糖、饱和脂肪、胆固醇、钠、钾、钙、铁、镁、锌和多种维生素。后续使用前应修复该脚本当前文件头的编码乱码，并把下载 URL 从写死版本改为可配置或依据官方发布清单更新。

### 黄豆、黑豆的关键歧义

FDC 可检索成熟大豆及多种黑色豆类，但“数据库里有相似英文名”不等于能安全生成中文别名：

- 中文“黄豆/大豆”应映射 *soybean / Glycine max*，不可映射 `yellow beans`；
- 中文“黑豆/黑大豆”通常指黑种皮大豆 *Glycine max*；USDA `Beans, black` 常指黑龟豆等 *Phaseolus vulgaris*，营养和烹饪用途不同；
- raw、cooked、boiled、dry/mature seeds 的每 100g 含水量相差很大，必须拆成不同 canonical 条目。

因此 USDA 适合补“来源明确的英文 canonical + FDC ID”，中文别名只能在学名/分类、食物状态和重量口径一致后审核加入。项目现有 TFDA 审核清单已经把 `Beans, yellow`→黄豆和 `Beans, black`→黑大豆列为危险错误映射，应继续作为硬门禁。

## 3. 中国大陆食物成分表：语境最匹配，但商业许可受限

中国疾控中心营养与健康所、中国营养学会的官方查询平台展示“中国食物成分表”数据。其黄豆页面列出“黄豆[大豆]”，黑豆页面列出“黑豆[黑大豆](干)”，均给出每 100 克的食部、能量、蛋白质、脂肪、碳水和微量营养等，因此可确认用户举例的两种常见食物均已收录。[黄豆官方查询页](https://nlc.chinanutri.cn/fq/foodinfo/326.html)；[黑豆官方查询页](https://nlc.chinanutri.cn/fq/foodinfo/327.html)

但是这两个官方页面都明确声明：数据来源于中国疾控中心营养与健康所建立的中国食物成分表，未经该所允许，任何单位和个人不得用于商业目的。Foodlink 属于产品数据库使用场景，不能把“网页可查”理解为“可抓取并商业复用”。[中国食物成分数据中心](https://fndc.chinanutri.cn/)

建议：

1. 现阶段只把它作为 TFDA/USDA 数据的中文名称、数量级和异常值核验来源，不复制整表数值；
2. 如希望将其作为中国大陆权威主源，直接联系中国疾控中心营养与健康所，书面确认商业 App 的存储、加工、展示、API 派生、更新和归因权限；
3. 未取得授权前，不写爬虫、不批量下载、不把查询结果转存到生产库。

## 4. FAO/INFOODS：标准与专项补充

FAO/INFOODS 官方维护食物成分数据库、区域表和专项数据库，并提供食物描述、组分标识符（tagnames）、数据质量与数据库编制相关标准。它的价值主要是帮助 Foodlink 统一“食物是什么、营养素是什么、数值如何产生”，以及补充脉豆、鱼类等专项或某些国家/地区的数据。[FAO/INFOODS Databases](https://www.fao.org/infoods/infoods/tables-and-databases/faoinfoods-databases/en/)；[FAO/INFOODS standards and guidelines](https://www.fao.org/infoods/infoods/standards-guidelines/en/)

限制是：INFOODS 门户链接到多个不同年代、不同维护机构和不同许可条件的数据集；它不是一个许可证统一的全球 API。导入任一表前应逐项确认下载页/工作簿内的版权与引用要求、版本、营养素定义、缺失值代码、单位、可食部和生熟状态。没有明确商业再利用许可的表，只能作为参考，不应因“由 FAO 页面收录”就推定可自由商业导入。

## 推荐实施顺序

1. **立即可做：TFDA 常用食物小批次。** 从真实未命中日志中选 Top 100～500，优先豆类、谷薯、蔬菜、肉蛋奶；用现有 TFDA importer dry-run，人工审核 canonical、别名、生熟/干湿口径和营养完整性，再按批次写入。
2. **黄豆/黑豆首批落地。** 至少分为黄豆（干、生重）、黑大豆（干、生重）及确有官方数据的熟制/粉/豆浆形态；不要让裸别名“黑豆”命中 USDA 黑龟豆。
3. **USDA 作为第二来源。** 优先 Foundation + SR Legacy；保留 FDC ID/data type/release，中文别名进入候选审核，不自动上线。Branded 暂不全量导入，避免大量美国包装 SKU 污染中文常用库。
4. **大陆表只做核验，等待授权。** 若获得商业许可，再单独设计带版本和权利信息的导入器。
5. **FAO/INFOODS 用于标准化。** 先采用其食物描述、营养素标识和缺失值原则，再逐数据集审许可，不整库盲导。

## 导入质量门禁

- 主键保留源 ID；每条保存来源 URL、数据集版本/下载日期、许可、原名和原始值快照哈希。
- `canonical_name` 必须带食物状态和重量口径；raw/cooked、dry/as served 不合并。
- “0”“未检测”“微量”“缺失”“未分析”不得统一写成数值 0。
- 别名只表达同一物种、同一部位、同一加工状态的同物多名；上下位类和相似食物不得建别名。
- 对能量与三大营养做单位换算、合理范围和 4/4/9 闭合检查；异常进入候选区，不直接 active。
- 每批先 dry-run，输出新增/更新/冲突/拒绝清单；人工抽检后再事务写入，并验证幂等复跑。
- 图片许可与营养数据许可分开处理；食物成分开放不代表其网页图片也可复制。

## 最终判断

用户提到的黑豆、黄豆都有权威网上数据。Foodlink 无需依赖模型猜数值，也无需先购买大陆成分表授权才能解决当前缺口：**先使用许可清晰、中文覆盖较好且项目已有导入器的 TFDA 开放数据，是风险最低、落地最快的方案；USDA 用作补充，大陆中国食物成分表等待商业授权，FAO/INFOODS 用于标准和专项补充。**
