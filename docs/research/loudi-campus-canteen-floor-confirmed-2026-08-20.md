# 娄底高校食堂实际楼层严格核验（2026-08-20）

## 结论

本轮以教育部院校标识码对应的现行普通高校为主体基线，核验娄底市 4 所普通高校，并补查校名沿革、合并办学、共享培养与外地主体在娄底设置正式校区的风险。只有同时满足以下条件的记录才进入严格 Active 集：

1. 学校主体仍然有效，校区是学校当前正式办学地点；
2. 能确定唯一物理父食堂，不能把档口、楼层餐厅、经营商或活动地点重复建成父食堂；
3. 一手官方来源明确该楼层发生售餐、取餐、堂食或开餐；
4. 有 2024—2026 年同一父食堂的当前运营闭环；
5. 招采、装修、消防、设备、建筑总层数不能单独证明实际开餐。

最终严格集为：

| 学校 | 正式校区 | 物理父食堂 | 实际餐饮楼层 |
|---|---|---|---|
| 湖南人文科技学院（4143010553） | 校本部（目录标准名） | 阳光公寓学生食堂 | 1F、2F |
| 湖南人文科技学院（4143010553） | 校本部（目录标准名） | 淳和楼食堂 | 4F |

计数：**1 所高校、1 个正式校区、2 个唯一物理父食堂、3 条实际餐饮楼层关系**。

其余 3 所高校本轮严格为 0。不是否认其存在学生食堂，而是截至核验日没有一手材料把“唯一父食堂—实际开餐楼层—当前运营”完整闭合。

## 二、严格 Active 记录

### A. 湖南人文科技学院校本部—阳光公寓学生食堂—1F、2F

#### 物理父体与楼层去重

官方历史开餐通知把同一楼体写为“阳光公寓一楼……餐厅、二楼新雅餐厅”；2025 年通知又把一楼经营别名更新为“汇鼎餐厅”，二楼仍为“新雅餐厅”。这说明汇鼎、新雅是同一阳光公寓学生食堂内的楼层餐厅/经营别名，不是两栋唯一物理父食堂。

因此目录只建一个父实体：`阳光公寓学生食堂`，楼层为 `1F`、`2F`；`汇鼎餐厅`、`新雅餐厅`只保留在别名或证据备注中，不能重复建父食堂。

#### 当前实际开餐证据

- URL：https://www.huhst.edu.cn/jjc/info/1100/5952.htm
- 题名：《关于学校食堂“十一”期间开餐安排的通知》
- 发布机构：湖南人文科技学院后勤基建处
- 日期：2025-09-29
- 原文关键片段：通知直接列出“阳光公寓汇鼎餐厅一楼”“新雅餐厅二楼”，并分别给出国庆期间停餐、恢复开餐安排。
- 证据意义：这是非招采的实际供餐时间表，同时绑定了当前父体、餐厅别名与 1F/2F；足以证明这两层是实际餐饮楼层，而非建筑层数。

#### 结构交叉证据

- URL：https://www.huhst.edu.cn/xwzx/tzgg/93.htm
- 题名：《2023年上学期食堂开餐通知》（学校通知公告索引保留全文摘要）

- 日期：2023-02-06（索引发布日期 2023-02-09）
- 原文摘录：“阳光公寓一楼天泽餐厅、二楼新雅餐厅2月11日中餐正常开餐。”
- 证据意义：证明阳光公寓学生食堂的 1F/2F 是长期真实开餐结构；同时揭示一楼经营别名由“天泽”变为“汇鼎”，进一步支持按物理父体合并，而不是随经营商名称新建重复食堂。

#### 反向挑战

- 不建立“汇鼎餐厅”和“新雅餐厅”两个父食堂：它们分别占同一学生食堂楼体的 1F/2F，且一楼名称曾随经营主体变化。
- 不因为国资处办公室位于“阳光公寓新食堂4楼”就加入 4F：办公室地址不是售餐、取餐或堂食证据。
- 不把同一楼体的办公室、团委地址或活动地点当成餐饮楼层。

### 娄底职业技术学院医卫校区与旧卫校

医卫校区属于现行娄底职业技术学院，不把原娄底卫生学校、医学部或医学院作为独立普通高校。综合校区与医卫校区可分别建校区，但旧“第二/第三食堂”不能在缺乏同父继承证据时自动迁移到现行南苑学生食堂。

### 娄底幼专旧名

娄底幼儿师范高等专科学校由原娄底幼儿师范学校升格而来；旧中职名称不是另一所普通高校。2026 招生章程明确现行主体及唯一荷叶路办学地点。

### 楚怡工匠计划与共享培养

湖南人文科技学院与娄底职业技术学院合作开展的“楚怡工匠计划”属于联合培养，不使娄底职院综合校区自动变成湖南人文科技学院的正式校区。没有学校章程、事业单位登记或现行招生章程将该地点列为湖南人文科技学院独立正式校区，因此不得跨主体复制食堂。

### 外地主体在娄底的正式校区

本轮补查了“大学城”“产业学院”“实践基地”“联合培养”“附属教学点”等表述。没有找到外地普通高校在娄底设立、由其章程或主管部门确认的正式校区，同时还能闭合食堂实际楼层。产业学院、实习基地、培训点和继续教育教学点均不作为正式校区。

## 六、最终反向审计

| 挑战问题 | 审计结果 |
|---|---|
| 是否把同一楼体的楼层餐厅重复建成父食堂？ | 否。汇鼎/新雅合并到阳光公寓学生食堂；润甜归淳和楼食堂。 |
| 是否用招采、维修、消防或消杀单独激活？ | 否。淳和楼 1—3F、娄职医学院 2F 等均排除。 |
| 是否把建筑楼层或办公室楼层当成餐饮楼层？ | 否。阳光公寓 4F 办公地址不纳入。 |
| 是否把旧餐厅名无条件继承到当前？ | 否。只保留有 2025 当前开餐闭环的父体和楼层。 |
| 是否把联合培养地点当成外校正式校区？ | 否。楚怡工匠计划不改变校区法人归属。 |
| 是否因“找不到反证”而 Active？ | 否。缺少正面一手证据的三校全部保持 0。 |

最终严格结论再次确认：**1 校、1 校区、2 个物理父食堂、3 条楼层关系；其余 3 校 0 Active。**
