# 常德市高校校区—父食堂—实际餐饮楼层一手来源严格确认（2026-08-20）

## 1. 结论摘要

本报告以全国校园目录审计中常德市 7 所零覆盖 `regular` 高校为基线，并补查外地主体在常德的正式校区、旧名、转设、合并前主体、共享校区、继续教育教学点和筹建院校。严格 Active 必须同时闭环：现行普通高校身份及学校标识码、学校明确的正式校区与精确地址、唯一物理父食堂、明确的实际售餐/取餐/堂食楼层，以及 2024—2026 同一父食堂当前实际供餐。

建筑总层数、活动地点、办公室或房间号、招采/招租/装修/规划单证均不单独激活；档口、品牌、楼层厅、标包和菜品不得拆成父食堂。同一父食堂跨层经营时只保留一个父实体，再挂多条楼层关系。

- 7 所基线高校均在湖南省教育厅截至2025年9月30日的普通高校名单内；常德学院是湖南文理学院芙蓉学院以同一学校标识码 `4143012657` 转设后的承接主体，旧学院已撤销，不重复建校。
- 可确认的正式常德办学校区共 **9 个**：湖南文理学院2个、湖南应用技术学院2个，其余5校各1个。湖南文理学院“老校区”是西校区内部老片区，不是第三校区；常德科技职业技术学院的两所合并前中职学校也不再作为高校校区保留。
- 未确认任何外地主体另设、现行招生且可独立实例化的正式“常德校区”。继续教育教学点、培训中心、附属中小学、合作产业学院、职教城共享设施和筹建项目均不据此造校区。
- 最终严格可上传集为 **2所学校、2个Active校区、2个物理父食堂、3条父食堂—实际餐饮楼层关系**：湖南文理学院西校区—一食堂—1F；湖南应用技术学院西校区—二食堂—1F、2F。
- 其余5校不是判断为“没有食堂”，而是截至核验日没有找到同时满足“一手来源 + 唯一父食堂 + 实际餐饮楼层 + 当前运营”的闭环；不得把待审核项无条件改为 Active。

本报告只给出证据结论；不生成 seed，不写数据库或业务代码。

### 主体继承、校区称谓和外地主体边界

1. 教育部[《关于同意湖南文理学院芙蓉学院转设为常德学院的函》](https://www.moe.gov.cn/srcsite/A03/s181/202503/t20250314_1182961.html)，教育部，函日2025-02-21、页面发布2025-03-17，原文：“同意湖南文理学院芙蓉学院转设为常德学院，学校标识码为4143012657；同时撤销湖南文理学院芙蓉学院的建制。”因此旧名与现名是同代码承接关系，不能重复建校，也不能把旧学院历史共享地址复制为常德学院的第二校区。
2. 湖南文理学院[《湖南文理学院春季师范生专场招聘会邀请函》](https://sxzz.huas.edu.cn/info/1160/5965.htm)，学校相关部门，2026年，写活动地点“湖南文理学院老校区体育场”，同时列“学校地址：常德市洞庭大道3150号”；学校2026招生章程把洞庭大道3150号明确命名为西校区。常德市自然资源和规划局[《湖南文理学院校园规划优化调整及西院过街天桥建设项目批前公示》](https://zrzyhghj.changde.gov.cn/zwgk/public/6617356/8366802.html)，2022年，又称“湖南文理学院西院新老校门”“西院新校区”，并说明解决“新、老校区跨滨湖路通行”。这些材料共同表明“老校区”是西校区内部老片区称谓，不另建第三校区。
3. 常德职业技术学院2025年度报告中的“红庙校区离退休党员活动室”是离退休人员活动地点，不能据此证明面向普通高等教育学生运行的正式第二校区。

## 3. 严格通过项

### 3.1 湖南文理学院西校区—一食堂—1F

- **现行身份与精确地址。** [《湖南文理学院2026年普通高校招生章程》](https://www.huas.edu.cn/info/1017/15757.htm)，湖南文理学院，2026-05-25，原文列学校国标代码 `4143010549`，并列“西校区地址：湖南省常德市武陵区洞庭大道3150号”。
- **“老校区”只映射到西校区内部片区。** [《湖南文理学院春季师范生专场招聘会邀请函》](https://sxzz.huas.edu.cn/info/1160/5965.htm)，湖南文理学院，2026年，原文同时出现“湖南文理学院老校区体育场”和“学校地址：常德市洞庭大道3150号”；这与2026章程的西校区地址相同。结合市自然资源和规划局2022规划公示对“西院新老校门”“新、老校区跨滨湖路通行”的表述，只能把“老校区”作为西校区内部片区别名，不能新建校区。
- **唯一父食堂、1F堂食与实际午餐逐句闭环。** [《守护开学“第一餐” 常德市场监管在行动》](https://scjg.changde.gov.cn/xwzx/ztzl/zzspaqwtlhhd/content_78143044)，常德市市场监督管理局，2025-02-25，先点名“在湖南文理学院老校区一食堂”，确定唯一父体；继而写“一楼餐厅宽敞明亮”，明确堂食楼层；同段列“手撕鸡、花菜、香肠、叉烧、麻辣烫、铁板烧、面点”等开学第一餐，并写后厨厨师“为师生们精心准备今日的‘第一餐’”、相关食材“均为今日学生们午餐的原材料”。因此这不是建筑层数或活动场所，而是 **老校区一食堂 → 一楼餐厅 → 面向师生的当日午餐/堂食** 的2025当前运营证据链。
- **归并结论。** 严格通过 `湖南文理学院/西校区/一食堂/1F`，只建一个“一食堂”物理父实体和一条1F关系。
- **反向挑战。** 同一市监报道还提到检查“一食堂、三食堂、四食堂两层楼和五食堂”。“四食堂两层楼”只说明检查范围或建筑层次，没有分别写明1F、2F的售餐、取餐或堂食，不能激活四食堂两层；其他食堂也没有精确楼层，均不从这篇报道扩张。

### 3.2 湖南应用技术学院西校区—二食堂—1F、2F

- **现行身份、校区和地址。** [《湖南应用技术学院2026年招生章程》](https://zs.hatu.edu.cn/zsshow/show1483.html)，湖南应用技术学院，2026-06-05，原文列国标代码 `4143013809`、办学地点“湖南省常德市鼎城区善卷路2058号”；学校简介明确“现有东、西两个校区”。[《2026年专升本免试生职业适应性测试方案（第一志愿）》](https://zs.hatu.edu.cn/zsshow/show1472.html)，学校招生就业处，2026-04-01，继续把报到、候考和测试地点写为“湖南应用技术学院西校区”，证明西校区现行使用。
- **1F实际售餐。** [《湖应校园生活小指南》](https://tw.hatu.edu.cn/show/610.html)，共青团湖南应用技术学院委员会，2022-10-15，介绍北方烤饼时明确“地点：二食堂一楼”，正文描述现场制作的手擀面、刀削面等具体食品与口味。地点、制作和菜品共同把二食堂1F绑定到实际售餐，不是建筑总层数。
- **2F实际售餐。** 同一指南介绍“千里香馄饨自选水饺”时写“二食堂二楼的……饺子种类丰富”，并标“地点：二食堂二楼”；黄焖鸡米饭、烤盘饭也分别标“地点：二食堂二楼”，其中烤盘饭写肉类可“自行挑选，称重计算价格”。具体菜品、选择和称价共同确认2F实际售餐。
- **2024同父当前续活。** [《校长李旋旗带队深入教学楼、食堂走访调研》](https://dzb.hatu.edu.cn/news/show992.html)，湖南应用技术学院党政办公室，2024-04-26，原文：“4月26日中午12:00……深入走访了西校区教学楼与二食堂，就学生错峰就餐问题进行了实地考察与深入调研”；并记载实地察看经营状况、保障食品质量及不同时段用餐需求。这直接点名同一父体“西校区二食堂”，且发生在午餐时段、围绕经营和就餐，不是未履约招采或纯装修材料。
- **2F更强当前交叉验证。** [《2025年11月教学督导工作简报》](https://pj.hatu.edu.cn/main/upload/202512/16/202512160931010903.pdf)，湖南应用技术学院教学质量监控与评估中心，2025-12发布，学生反馈中仍点名“食堂部分菜品价格偏高（如二食堂烤盘饭）”。该菜品与2022指南明确置于二食堂2F的“烤盘饭”相同，补强同父同菜品持续实际售卖；它不用于推导新楼层。
- **归并结论。** 严格通过 `湖南应用技术学院/西校区/二食堂/1F、2F`。北方烤饼、千里香馄饨、自选水饺、黄焖鸡和烤盘饭都是二食堂内部菜品/档口线索，不拆成父食堂；1F、2F也只是同一物理父食堂的两条楼层关系。
- **反向挑战。** 2024续活只点名西校区二食堂，不能把两条楼层关系迁移到东校区；2025烤盘饭只能补强已由2022明确定位的2F，不能由一款菜品反推出其他楼层。

## 4. 逐校排除项与最小补证

### 4.1 常德学院：当前食堂成立，父体和楼层均不够精确

- [《常德市卫生健康委到我校开展健康教育工作调研》](https://www.changdecollege.cn/info/3091/11731.htm)，常德学院，2025-12-19，原文记载调研组“实地走访学校食堂”，察看减油减盐措施、菜品搭配和经营情况，可证明现主体当前存在实际供餐。
- 学校[《食堂大厅2》](https://www.changdecollege.cn/info/1301/7481.htm)，常德学院，2025-05-19，是校园风光图片页；相邻还有“食堂大厅1”“食堂大厅3”。数字是图片标题/厅序号，正文没有说明它们是一楼、二楼、三楼，也没有唯一物理父食堂规范名，图片不能代替逐层文字闭环。
- **排除结论：** 泛称“学校食堂”无法确认唯一父体，“大厅2”不是2F证据。当前0 Active。
- **最小补证：** 学校/主管部门当前材料明确一个规范命名父食堂及“该食堂一楼/二楼……”正在售餐、取餐或堂食。

### 4.2 常德职业技术学院：多个父食堂有当前线索，无一条合格楼层关系

- [《常德职业技术学院2025年度报告书》](https://www.cdbb.gov.cn/ywgz/sydwdj/ndbggs/content_3165954)，常德事业单位登记管理机关，2026-06-30，2025年度履职中包含食品安全监管和“食堂饭菜价格平抑基金”，足以证明学校餐饮体系当前运行，但没有父食堂—楼层。
- 可检索到2024年媒体检查报道点名“学生一食堂、学生二食堂、教工食堂、特色食堂、小吃街”，并描述厨房、餐厅和窗口检查；该报道不是高校或主管部门一手发布，且仍无逐层售餐文字，只能作为检索线索，不能激活。
- “红庙校区离退休党员活动室”不能转换为正式学生校区；教工食堂、特色食堂和小吃街也不能在缺少物理边界证明时互相归并或拆分。
- **排除结论：** 当前0 Active。
- **最小补证：** 学校后勤、市监或教育主管部门当前材料，逐一把学生一食堂/二食堂等唯一父体绑定到明确楼层的实际售餐、取餐或堂食行为。

### 4.3 湖南高尔夫旅游职业学院：旧经营与第三方信息不能续活

- 湖南省教育厅2025高校名单和省级招生平台可确认现行学校、代码及清水湖办学地点；学校就业平台页面出现“第一教学楼一楼114室”，但这是办公室房间号，不是食堂楼层。

- **排除结论：** 当前0 Active；不得把“第一教学楼一楼”错配给食堂，也不得用2021旧经营线索单独续活。
- **最小补证：** 学校或市监部门2024—2026材料，明确清水湖校本部某唯一父食堂的具体楼层正在售餐/取餐/堂食；若使用旧精确楼层，还需同名父食堂当前运营续证。

### 4.4 湖南幼儿师范高等专科学校：现行地址明确，食堂楼层无一手闭环

## 5. 反向挑战与去重结论

- 湖南文理学院西校区一食堂：市监原文连续把“老校区一食堂”“一楼餐厅”和当日师生午餐绑定，允许激活1F；但“老校区”只映射到西校区内部片区，不另建校区，报道中的三/四/五食堂也不因被检查就生成楼层。
- 湖南应用技术学院西校区二食堂：1F、2F都有具体食品/称重售卖原文，并由2024同父午餐时段经营调研续活；多个菜品和楼层厅归并为一个二食堂父体、两条楼层关系，不拆品牌，不迁移到东校区。
- 常德学院与湖南文理学院芙蓉学院：同代码转设，旧学院建制已撤销；旧名、旧址、旧食堂和举办者湖南文理学院的食堂均不得复制给现主体。
- 湖南文理学院东/西两个正式校区必须分别绑定食堂证据；西校区的老/新片区、跨滨湖路通行和内部“西院”称谓不产生额外校区。
- 常德科技职业技术学院与原常德财经中专、原常德汽车机电学校：合并前主体不是现行普通高校分校区；旧食堂不得跨主体直接继承。
- 常德职业技术学院“红庙校区离退休党员活动室”、湖南高尔夫旅游职业学院“第一教学楼一楼114室”、常德学院“食堂大厅2”分别是活动点、办公室房间和图片/厅序号，均不是实际餐饮楼层。
- 本轮没有把建筑总层数、检查覆盖楼层、活动地点、办公室房号、图片编号、招采/装修/规划或第三方经营信息单独设为 Active；也没有发现可纳入的外地主体正式常德校区。
