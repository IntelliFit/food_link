# 称重科研计划 v2：独立入口与外卖称法（方案稿，2026-11-04）

v1（4.6.20 体验版，线上表和后端 11-03 已上线）按"一个碗、先称空碗"设计。实际用外卖试下来有三个问题：

1. 外卖盒到手就装着菜，空盒只能吃完才称得到。
2. 一顿外卖往往有好几个盒子，每个盒子各有容器，现在没法用一张合照记一整顿（同一张评测照不能用在两份样本里）。
3. 每个读数都要拍照再手打数字，三盒外卖要拍 8 张、打 6 个数，太麻烦。截至 11-04 线上 0 条样本。

## 1. 入口：从"贡献食物数据"里拿出来，单独成一个计划

- 「我的」页新增一组「科研共建」，只放一个入口：**称重科研计划**（说明：用食物秤称一顿饭，共建中餐克重评测集）。
- 「贡献食物数据」页删掉第 4 项和奖励说明里的称重部分，回到标准食物 / 包装食品 / 公共餐食三项。
- 计划有自己的首页（现在的页面拆成"首页 + 记录页"）：
  - 为什么做、怎么做（三张小图：拍 → 称 → 吃完称空盒）、奖励规则；
  - 我的贡献：已提交 / 已通过 / 待审核、我的常用容器；
  - **进行中的一顿**（待称空盒）放在最上面，一键继续；
  - 按钮「记一顿」。
- 页面路径保留 `packageExtra/pages/research-weight/index` 作为首页，视频和二维码直接链到这里；记录页另开一页。

## 2. 记录模型：一顿 = 一张合照 + 若干容器

| 层级 | 内容 |
|---|---|
| 一顿（样本） | 场景、地点、评测照片（整顿的俯拍 + 45°，必需；参照物和环绕视频可选） |
| 容器（1～8 个） | 名称（如"米饭""宫保鸡丁"）、连容器读数 + 读数照片、皮重来源、皮重读数 + 照片 |
| 容器内分项（可选） | 现有的"分项累加"，只用于能边打边称的场景（食堂、家里） |

v1 的"整份"和"分项"就是"只有 1 个容器"的特例，所以不另立模式，旧数据照样可读。

**皮重来源（每个容器各选一种）：**

| 来源 | 适用 | 证据 |
|---|---|---|
| 先称空容器 | 食堂、家里自己盛 | 空容器读数照片 |
| 秤已归零 | 先放空容器归零再装 | 归零照片 |
| **吃完再称**（新） | 外卖 | 吃完 / 倒掉剩菜后的空盒读数照片 |
| **常用容器**（新） | 同款外卖盒、自家碗盘 | 建容器时拍过一次，之后不用拍 |

规则：上秤时盒盖拿掉；皮重和连盒读数必须是同样的部件（都不含盖、不含筷子和酱料包）。吃不完先把剩菜倒掉再称空盒；可选再记一个"剩了多少"，以后用来算实际吃了多少。

**分开称还是一起称：**默认每个盒子分开称，这样每道菜都有自己的真值，最有价值。嫌麻烦也可以所有盒子一起上秤、饭后空盒一起称，这时只得到整顿总重（入评测集时标为总重样本）。

## 3. 外卖的实际流程（目标：三盒外卖 3 分钟内）

1. **拍**：盒盖全打开，像平时吃饭那样摆好，拍俯拍和 45° 两张（筷子放旁边可当参照物）。
2. **称**：每个盒子放上秤 → 拍读数 → 起个名字（可从识别结果里点选）→ 能选常用容器的直接选。「+ 再加一盒」。
3. **吃**：页面显示"吃完回来称空盒"，草稿保存在本机，首页显示为"进行中"。
4. **称空盒**：没选常用容器的盒子逐个称空盒拍读数；可勾选"存为常用容器"（如"美团 750ml 圆盒"）。
5. 提交。

有常用容器的话，第 4 步整个跳过。

## 4. 少拍少打字

- **常用容器库**：同款外卖盒每个之间只差几克，对一份 400g 的菜影响不到 1%；样本里记下皮重来自容器库，分析时可单独筛。
- **读数自动识别**（第二期）：拍秤照片后由视觉模型读出数字自动填上，用户只核对。证据照片照留，不再手打。
- 评测照片仍要求 2 张；每个盒子的单独照片可选。

## 5. 防错与数据质量

- 选"吃完再称"的容器，空盒照片的拍摄时间必须晚于评测照片，否则标出来给审核看（不直接拒，手机时间可能不准）。
- 皮重 ≥ 连盒读数、单盒超过 5000g、读数照片重复使用，照旧拒绝。
- 常用容器只能用自己的；容器重量改了以后，已提交的样本保留当时的重量。
- 审核页按容器显示连盒读数、皮重、皮重来源和对应照片；"吃完再称"顺序异常的样本标红。

## 6. 进评测集

- 多容器、分开称：每个容器一项（名称 → 净重），同名自动编号，另存总重。
- 一起称：只存总重。
- 元数据里带每个容器的皮重来源，评测时可以只看"先称 / 吃完称"的样本，或者把容器库样本单独比较。

## 7. 奖励（建议，后台可改）

整份 2 分；分项 4 分；多容器分开称 2 分 + 每多一个盒子 1 分，封顶 6 分。
