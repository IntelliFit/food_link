## 操作与性能边界

- “我的 → 均衡模式主题”增加“动态背景”开关，默认开启；关闭后保留静态场景。偏好保存到本机，所有缓存标签页同步。
- 页面隐藏时暂停，返回时按偏好恢复；系统减少动态效果的媒体查询会停用装饰层。
- 使用 CSS transform / opacity 动画，无逐帧 JavaScript、setData 轮询、视频或 GIF 下载。
- 每个场景最多六个装饰子层，pointer-events: none，不拦截按钮、滚动、照片长按。
- 阴阳养生模式不挂载该装饰层。健康数据、圈子照片、功能按钮不参与位移动画。
- 当前覆盖四页的主题场景区域；长列表和业务卡片保持静态。没有进行真机帧率、温度或耗电测量，不能据此声称所有设备上均达到特定帧率。

## 验证

专题单测覆盖本机偏好持久化、已挂载标签页同步、隐藏暂停/返回恢复、存储不可用降级；原有场景下载失败重试、业务入口与养生隔离测试继续保留。提交前执行 TypeScript、ESLint 和完整 Jest。

原生验证读取动画前后的 transform，区分“挂载了动效节点”和“实际正在运动”；逐页检查装饰层不拦截点击。报告会保留不含用户资料的检查结果；账号/圈子实拍只放本地。

尚需真机持续运行和多设备视觉复核。此轮是每主题独立动态语言的实现，不代表此前各主题与静态渲染图的全部差距已消除。

原生检查结果：八主题 × 四页共 32 处动效层生效，八种主动画采样的 transform 均变化，pointer-events 均为 none。静态开关关闭后 play-state=paused、两次采样位置一致；重新开启后恢复。切换 Tab 时旧自动化页面句柄被销毁，无法据其查询隐藏页面的暂停类；隐藏/返回逻辑由生命周期单测覆盖，不将该原生项目记为通过。详见 runtime-check.json 与 toggle-check.json。

运行检查发现小程序编译器会移除通配符子选择器，已将暂停与减少动态效果规则改为显式 view/image 选择器，并在模拟器复验真正停止；另按首页实拍将水纹中心调回水池平面。
