# 伙伴冒险与成长小屋

用户最新选择为“宠物成长与收集：闯关解锁、装扮、小屋和故事”。本轮以此为主，把动作冒险作为收集入口。入口为聊天 → 宠物时光 → 伙伴的冒险时光，路由 `/packagePetStudio/pages/adventure/index`。原有单人餐车保留。

## 可以玩的流程

1. 小屋展示账号当前宠物；模板和照片生成角色继续使用原档案。鬼鬼复用用户确认的眼镜、黑上衣、米色裤子原精灵。
2. 三跑道湖畔冒险：左右换道、起跳、蓄力冲刺。岩石可以跳过或冲开，树桩必须换道，水洼需要起跳；连收叶片与星光获得连击。
3. 三章六关，45/50/60秒渐进。三颗爱心、碰撞后保护时间、暂停及后台冻结。角色随滑板整体起跳，不扭曲原角色身体。
4. 有效结算获得冒险经验与星光，解锁下一关及对应章节故事。失败也保留实际收集到的星光，不把游戏当作真实运动或饮食记录。
5. 收藏铺兑换绿植20、灯具30、叶纹滑板40、围巾30星光。兑换只扣一次；已有装备可穿戴/收起，摆件可放在三处位置或移动，不重复生成。
6. 小屋与游戏中显示实际装备。装扮不增加成绩或能力；金色围巾目前仅适配用户确认的原精灵，其他体型不会误扣款或套上错误形象。

## 保存与资源边界

资源是本机“星光”，不是现有奖励积分，也不是服务端代币。每日最多60颗，通关加3颗，实际拾取星光另计；经验每局最多80。参数是本轮可玩版本的配置，仍需试玩评估节奏。

存储键为 `pet_adventure_progress_v1:<account>:<pet>`，保存经验、星光、已解锁/通关、最佳成绩、背包、装备、三个摆件槽、章节及已结算局号。重复回调或重试不会重复发放。读取或写入失败不显示假成功，不用空进度覆盖旧存档；保存失败时保留本局、提供重试并阻止开启新局。切后台与终局竞态保留收获，切账号后旧结果不能写入新账号。

“我的 → 清除缓存”会重置这些本机数据。尚无云存档、跨设备同步、真人匹配PK、服务器复算或交易账本；不会改变宠物云端身份、现有奖励积分及真实健康记录。训练任务与生活记录奖励仍是后续工作。

## 视觉与验收

沿用已经确认的温暖木屋、奶油色、湖畔绿意方向。使用真实场景、透明道具图集和短围巾素材，来源与压缩记录见 [assets.md](assets.md)。四项新增资源约510KiB，位于独立分包。

自动检查覆盖固定步长碰撞、跳跃/冲刺、暂停、可通关性、结果校验、重复结算、每日上限、库存/装备/摆放和页面保存失败与账号隔离。原生微信验证结果另见本目录 `verification.md` 与根目录 `design-qa.md`；规则测试和节点尺寸不能代替最终视觉试玩。
