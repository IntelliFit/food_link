## 实现约束

- 四个页面继续读取现有真实业务数据，不用效果图中的示例数值覆盖接口数据。
- 阴阳、太极和成熟黄色葫芦仅属于养生模式，不进入均衡模式主题。
- 主题差异需要同时体现在构图、字体、间距、数据图形、内容容器、功能入口与动效上。
- 保留可读性、触控尺寸、空状态、加载状态和深浅色边界，不为了视觉牺牲功能。
