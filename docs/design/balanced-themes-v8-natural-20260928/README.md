# 自然共生：纸张、年轮与标本抽屉

参照：`../balanced-themes-v3-20260927/02-natural-symbiosis-four-surfaces-v3.png`。
本轮仅精修自然共生，其他主题继续保留独立结构。阴阳养生模式不使用这些素材。

## 四页改动

- 首页：保留植物主视觉，将记录入口做为木框纸签，调整叶片信息入口的尺寸、边框、透明度与位置。
- 分析：新增透明木质年轮底图，与真实七日摄入 Canvas 图分层；图片等比适配，避免横向拉伸。纸纹贯穿页面，日期范围置于年轮上方。
- 圈子：取消厚重圆角卡片，保留单图记录的左图右文结构，使用纸面笔记与细分隔线。
- 我的：资料区融入纸面，功能分类改为木质标本抽屉，保留原有展开、收起与业务入口。

## 验证与剩余差距

微信原生运行检查已通过首页、分析、圈子、我的主题一致性、日期选择及分类展开/收起。实际截图发现并修复纸纹被旧背景遮挡、年轮拉伸两个问题。开发者工具截图接口间歇超时；成功截图分辨率为 224×488，不能替代真机高清验收。

原生证据保存在本地 `.local-state/`，不把账号或圈子图片上传仓库。提交时执行 TypeScript、暂存 ESLint 与完整 Jest 门禁。
