# 水之道 V6：场景与真实记录

本轮先强化水之道的首页、分析、圈子、我的，参照 V3 的水滴、玄石、流水和编辑式排版。其他七套主题和养生模式的页面结构保持原有实现。

## 实现

- 首页使用独立透明水珠素材承载三个真实操作：记录饮食、饮水、查看分析。右侧展示真实当日餐数，底部光影淡入页面底色；修复后续问候文字在深色背景上的对比度。
- 分析页加入七个日期节点，点击查看对应饮食摄入和饮水记录。日期跨月连续，来源为原始统计接口，未使用现有分析页的示例数据。缺失、零或无效摄入数值显示为暂无记录，不解释为实际未进食。
- 游客可以查看七日布局与空态，但不会显示缓存账号数据。登录入口沿用既有登录守卫；已登录用户可回首页记录。月视图新增节点区只回看该周期末尾七天，原月统计保持可用。
- 分析、圈子和个人页改用新的玄石流水背景，避免重复使用首页餐盘主视觉。圈子采用通栏照片、细线分隔；个人资料融入场景，功能分类保留点击折叠。
- 统一水之道的消息入口、登录提示、主题入口及功能图标材质。所有样式仅作用于水之道，未改动养生阴阳。

## 验证与边界

- 专项测试覆盖跨月日期、切换查看真实值、仅饮水记录、游客隔离、切换周期和无效数值。
- 原生运行已确认首页、圈子及七日节点；点击日期切换选中状态通过。首页与圈子取得可辨识实拍。
- 开发者工具截图仍有间歇性超时，错误页面或空白截图未作为验收证据；完整四页逐图和多设备验收尚未完成。过程实拍保存在本地忽略目录，不上传账号及圈子个人内容。
- 七日节点为日期选择器，不以位置或大小暗示数值；精确数值在详情显示。原有趋势图继续保留，尚未重绘为水波曲线。
- 现有主包超限问题未在本轮解决，本地大包调试配置不随业务提交上传。
