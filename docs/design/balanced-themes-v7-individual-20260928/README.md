## 数据与操作

- 新分析主体始终使用 `sourceData` 原始统计，不使用旧分析页的示例对象。月视图下明确显示周期末尾的“近七日”；原月度与详细分析仍在下方。
- 平均摄入仅对已记录日期求平均。API 为 0、缺失或无效数值时显示 `—`，不将其解释为实际未进食。
- 山水/河流/水面曲线在未记录日断开，不跨过缺失日绘制连续趋势。自然年轮从外到内对应七日，弧长按本周最大摄入值缩放，不代表目标完成率。
- 艺廊环图表示七日摄入的日期占比，日期按钮的色条与图例一致，不将其标为营养素比例。没有数据时不制造分布。
- 绘本分镜背景是主题装饰插画，明确说明不是用户照片。当天饮食和饮水详情取真实数据。
- 日期选择、登录/记录入口复用实际操作；游客不展示缓存账号数据。
- 个人分类依旧点击展开/折叠。微缩目录展开时横跨两列，子项目保留原业务点击与登录守卫。
- 圈子只对普通单图饮食动态采用主题排版。运动、自定义动态、多图、评论、点赞和图片预览沿用现有行为。
- 阴阳养生模式保留原结构；没有引入均衡模式的年轮或主题目录装饰。

## 代码归属

- `ThemeChapterHeader.tsx`：八个独立页头结构。
- `ThemeDailyReview.tsx`：八个独立分析组合，复用日期归一化与 Canvas 绘图能力。
- `ThemeProfileSection.tsx`：可折叠的真实分类入口。
- `styles/themes/<theme>.scss`：每套主题单独维护首页、圈子、个人页样式。
- `theme-reviews.scss`：各分析构图及图表布局。
