# 温暖的宠物时光：首版界面与交互

视觉依据为本目录 `reference.png`，用户确认的暖木、奶油色、绿植湖畔方案。角色使用项目原素材，不将鬼鬼、小麦、豆豆重绘成统一的新角色。

## 入口与可用功能

- 聊天顶部 → 宠物时光，或我的 → 宠物小屋 → 温暖的宠物时光；独立分包 `/packagePetStudio/pages/index/index`。
- 衣橱、动作、游戏乐园三个页签；当前宠物与接口返回的模板可以分别预览。模板预览不修改账号当前宠物。
- 鬼鬼当前原精灵支持免费围巾静态试穿；原素材保持不变。搭配只存当前账号/设备的宠物空间，可从“我的 → 清除缓存”重置，不自动覆盖首页装扮。
- 围巾仅对已适配的原精灵开放，其他体型显示待适配。拍照生成入口继续使用既有宠物小屋流程。
- 动作只展示当前角色实际拥有的帧：原精灵待机/行走，有压缩和起跳帧的角色支持跳跃播放，其他角色保留待机；未制作动作不借用其他角色。
- 游戏乐园默认展示伙伴冒险，页首提供成长小屋的独立入口。三章六关、换道/起跳/冲刺、星光收集、装扮兑换、三处摆件及故事解锁见 [冒险与成长实现说明](../pet-adventure-20261001/implementation.md)。原20秒节奏练习已移除。
- 宠物餐车保留六个90秒单人关卡、十二份配方、三个并行工位、选料、控火、装盘、出餐、顾客耐心、连击、星级结算和本机纪录。操作及规则见 [餐车实现说明](kitchen-implementation.md)。合成、水岸尚在制作。
- 奖励余额读取现有奖励积分接口，失败显示横线。冒险星光为当前账号/宠物的本机资源，与奖励积分分开；可兑换冒险装扮和小屋摆件，不可提现、交易或跨设备同步。
- 宠物小屋和聊天的当前头像复用桌面外观偏好。成功选择新模板或重新生成照片角色后恢复跟随新档案；只改名字不重置形象。

## 尚未开放

真人匹配、对战同步、胜负裁定、服务端游戏奖励账本、合成与水岸完整游戏、首页/聊天跨页面换装，以及新角色动作的制作和其他体型服饰适配。冒险收藏和换装只在成长小屋与冒险中生效；餐车成绩只存本机，不发放星光或写入真实饮食记录。
