# 温暖的宠物时光：首版界面与交互

视觉依据为本目录 `reference.png`，用户确认的暖木、奶油色、绿植湖畔方案。角色使用项目原素材，不将鬼鬼、小麦、豆豆重绘成统一的新角色。

## 入口与可用功能

- 我的 → 宠物小屋 → 温暖的宠物时光；独立分包 `/packagePetStudio/pages/index/index`。
- 衣橱、动作、对战三个页签；当前宠物与接口返回的模板可以分别预览。模板预览不修改账号当前宠物。
- 鬼鬼当前原精灵支持免费围巾静态试穿；原素材保持不变。搭配只存当前账号/设备的宠物空间，可从“我的 → 清除缓存”重置，不自动覆盖首页装扮。
- 围巾仅对已适配的原精灵开放，其他体型显示待适配。拍照生成入口继续使用既有宠物小屋流程。
- 动作只展示当前角色实际拥有的帧：原精灵待机/行走，有压缩和起跳帧的角色支持跳跃播放，其他角色保留待机；未制作动作不借用其他角色。
- 四款游戏保留厨房、合成、运动、水岸方向。运动页有20秒节奏练习：中心命中10分、邻近5分，250ms重复点击保护，切换页签或隐藏页面停止。
- 奖励余额读取现有奖励积分接口，不虚构“食光币”账户、不发放游戏币、不扣币。余额请求失败显示横线。
- 宠物小屋和聊天的当前头像复用桌面外观偏好。成功选择新模板或重新生成照片角色后恢复跟随新档案；只改名字不重置形象。
