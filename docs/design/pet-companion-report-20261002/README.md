## 重建

`build_web.mjs --modules <node_modules目录>` 使用 Node、Sharp 与 Playwright Chromium，仅渲染文档，生成候选界面PNG和离线HTML；它不会启动小程序或任何常驻服务。现有角色与素材从仓库复制，新增背景保存在 `assets/`。可使用Codex bundled运行时。

`build_pdf.py --check-only` 用Python检查全文、字体和图像；`build_pdf.py` 用ReportLab生成PDF。需要Pillow、ReportLab、中文字体及当前目录的PNG配图。修改后应重新渲染并进行视觉检查。

本报告未将未来动作、真人PK、云账本或完整四款游戏标为已实现，设计数值需要试玩验证后再进入产品。
