# 九主题首次登录动画

首次认证登录先展示“食探更新速递”，说明九种风格、可自行控制的动画浏览，以及默认选择与已有记录保留；随后介绍八个均衡主题和阴阳养生主题。当前章采用八秒视频循环，用户左右滑动切换，不再定时自动翻页；可暂停、继续、回看或查看文字介绍。最后一页提供九项选择，未预选；用户主动确认后保存模式及所选均衡主题。已有完成标记继续有效，之后从“我的”切换模式，不重复开屏。

更新页作为新增首张，使用可编辑的原生文字和纸片轻动效，遵循页面暂停和前后台状态；没有额外视频文件或生成费用。整个流程现为十一张：更新一张、主题九张、选择一张。内部主题编号及选择映射保持原值，Swiper 索引整体加一；重新观看回到更新页。版本文案沿用应用版本常量，没有独立发布版本或实际推送通知。

## 素材与加载

采用用户确认的本地程序动效视频，无付费生成。十段 H.264、24fps、无音轨的视频含最后的选择页；每段配 JPEG 首帧。2026-10-16 按用户要求移除底部进度条：前九章封面与视频同步保留顶部 640×1214，去掉烘焙的旧进度、页码、暂停和下一章区域，主题介绍与受众图标保留；最终选择页保持 640×1384。以原比例和原起点显示，无中心裁切；顶部原生暂停键和底部滑动提示替代旧导航。文件名、SHA、字节数和缓存 revision 同步升版，避免继续读取 v1 缓存。

原生资源所有者放在三个独立分包，图片实际就绪后仅复制当前视频至版本化本地缓存，收到真实播放进度才显示视频。原生 Swiper 只挂载当前章一个解码器，相邻章只展示海报，`motion=false` 不复制视频。主包不直接读取异包图片，也不把未解码视频覆盖到首帧上。

`src/mode-introduction-assets.json` 定义章节、资源所有者、文件大小、实际媒体高度及视频 SHA。更换素材须更新 manifest、原生组件的资源映射及缓存 revision；保持每个资源分包低于微信单分包限制。2026-10-16 开发产物三个资源分包不含 source map 分别为 1,484,930、1,481,877、1,671,087 字节；这不是整个应用的发布包体积认证。

## 状态与恢复

每章只保留一个播放实例，退出页面立即暂停。区分用户暂停与页面隐藏：返回前台恢复原来正在播放的动画，手动暂停保持暂停。原生自动暂停后尝试恢复，初次播放与中途停滞均有超时处理；旧实例回调及异步资源回调有生命周期守卫。失败时提供重试及可滚动的文字介绍，不能因资源故障保存默认选项。末页选卡、确认、重看均拦截滑动后的迟到点击，防止误保存。

确认操作核对账户及会话，先写账户模式、账户主题与原生底栏兼容镜像，最后写完成标记；写入验证失败回滚。只有成功持久化后通知页面订阅者。养生选择保留原均衡主题。账户主题优先于全局兼容值，A/B/A 切换能恢复各自确认过的主题。
