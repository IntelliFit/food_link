# 九主题首次登录动画

首次认证登录依次展示八个均衡主题和阴阳养生主题，每章八秒，可暂停、继续、回看或查看文字介绍。全部章节结束后展示九项选择，未预选；用户主动确认后保存模式及所选均衡主题。已有完成标记继续有效，之后从“我的”切换模式，不重复开屏。

## 素材与加载

采用用户确认的本地程序动效视频，无付费生成。十段 H.264、640×1384、24fps、无音轨的视频含最后的选择页；每段配 JPEG 首帧，按原比例完整显示。原生资源所有者放在三个独立分包，图片实际就绪后仅复制当前视频至版本化本地缓存，收到真实播放进度才显示视频。主包不直接读取异包图片，也不把未解码视频覆盖到首帧上。

`src/mode-introduction-assets.json` 定义章节、资源所有者、文件大小及视频 SHA。更换素材须更新 manifest、原生组件的资源映射及缓存 revision；保持每个资源分包低于微信单分包限制。当前开发产物三个新分包不含 source map 分别为 1,684,886、1,654,137、1,856,024 字节；这不是整个应用的发布包体积认证。

## 状态与恢复

每章只保留一个播放实例，退出页面立即暂停。旧实例回调、暂停结束边界和异步资源回调均有生命周期守卫。失败时提供重试及可阅读的文字介绍，不能因资源故障保存默认选项。

确认操作核对账户及会话，先写账户模式、账户主题与原生底栏兼容镜像，最后写完成标记；写入验证失败回滚。只有成功持久化后通知页面订阅者。养生选择保留原均衡主题。账户主题优先于全局兼容值，A/B/A 切换能恢复各自确认过的主题。

- 十段实际运行视频全解码通过，源码与 dist 视频 SHA 一致；独立复审确认 33 个媒体、原生组件及共享 helper 文件与源一致。
- 官方 miniprogram-automator 获取十章真实截图；已目视检查九主题构图、最终选择页及批准稿同宽对照。暂停两张场景截图像素相同，恢复播放后场景改变；九项选择互斥、未选禁用确认，浏览及选中前后的偏好指纹一致。

- 本轮未在实际账户点击最终确认，持久化由自动化测试覆盖。开发者工具原生检查不代替实体手机、不同尺寸设备及总体发布包体验收。
