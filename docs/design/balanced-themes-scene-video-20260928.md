# 均衡主题：原画图生视频

用户要求背景画面本身动态化。V9 的 CSS 叠加枝叶、云和水纹不符合此要求，本轮撤下。采用用户指定的即梦平台，以已有主题原画制作场景视频。

## 当前状态

- 即梦创作页已打开，当前等待用户登录，尚未提交生成任务或取得视频。
- 已准备水之道首页原图的 PNG 格式副本，750×1125，不改变构图。
- 小程序新增场景视频组件：静音循环、隐藏页面卸载、播放出错保留静态图、实际播放后再显现。缺少视频配置时仅显示原画。
- 八主题视频映射暂为空；界面不会把未生成的主题标为动态。
- 单测覆盖静态回退、首帧显示、静音循环、隐藏卸载、播放错误和切换资源恢复。实际视频播放、首尾循环、微信真机层级与功耗仍待取得素材后验证。

## 首支试片：水之道

参考图：`apps/wechat/src/packageThemeScenes/assets/water-vessel-v4.webp`。

提示词：

> 以上传图片作为唯一场景参考，固定机位，锁定原有构图、玻璃水滴形器皿、食物和石台的形状、位置与材质，不推拉摇移镜头。仅让原画右后方的瀑布持续自然下落，底部水面产生轻缓、符合透视的涟漪与反光流动。器皿和食物保持静止、边缘清晰，不融化、不变形。保持暗色高级摄影质感，节奏克制安静。无文字、无新物体、无额外粒子或叠加光圈，静音。首尾构图、亮度和水流速度一致，适合连续循环播放。

优先使用平台当前支持的首尾帧模式，首尾均使用原图；时长、比例以实际模型选项为准，先生成一支短片检查质量。不可用提示词承诺代替实际循环验收。

## 各主题运动方向

| 主题 | 原画内部运动 | 必须稳定的内容 |
| --- | --- | --- |
| 清晰秩序 | 食物静物中的轻微蒸汽、真实柔光变化 | 餐具、几何结构、食物形态 |
| 自然共生 | 原画枝叶自然受风、叶影随枝叶变化 | 纸张与标本结构 |
| 东方雅集 | 山间原有云雾缓行、水面微动 | 山体、建筑与水墨笔触 |
| 现代艺廊 | 拼贴画内部的几何雕塑缓慢转动 | 构图重心、画框和留白 |
| 微缩世界 | 原有河水流动、树冠轻动 | 建筑、道路和微缩比例 |
| 绘本陪伴 | 原画茶汽与窗帘轻动，保留手绘笔触 | 分镜边界、人物与桌面布局 |
| 清朗关怀 | 原有窗光、室内植物的缓慢变化 | 清晰对比和阅读区域 |
| 水之道 | 瀑布、水面反射与涟漪 | 玻璃器皿、食物和玄石 |

素材中不存在的物体不凭空加入。纯色背景的主题先制作符合既有布局的专属底图，再图生视频；不将业务 UI 截图直接生成视频。首页、分析、圈子、我的按各自原画配置，不强行复用不同构图的视频。

## 接入验收

1. 逐帧检查主体形变、纹理漂移、首尾跳变和闪烁，拒绝用整体缩放替代场景内部运动。
2. 导出无音轨的 H.264 MP4，保留原画裁切逻辑。视频按主题按需加载，评估包体后确定分包或已授权 CDN 存储。
3. 在 `theme-scene-videos.ts` 填入已验证的资源地址，不填虚构 URL。
4. 微信开发者工具及真机验证视频在内容后方、不会遮挡按钮、切页停止、关闭动态后回到原画、失败无黑屏。
5. 检查四页背景与各自静态原画匹配，用户数据和交互仍由原业务组件呈现。
