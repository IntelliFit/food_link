# 宠物区入口与触摸按键整理

本次范围是伙伴时光中的小屋、成长、收藏、故事，以及游戏选择、兑换、出行工具入口。沿用现有温馨小屋的奶油底色与鼠尾草绿，按用途分别设计控件，减少重复边框与字符图标。

| 入口 | 调整后的形式 |
| --- | --- |
| 喝水、锻炼、工作、休息 | 整张行动卡可触摸，独立水滴、哑铃、公文包、月亮图标；标题、奖励、说明与操作提示分层 |
| 游戏开始 | 清楚的绿色主按钮，游戏选择卡保留场景预览；修正通用样式覆盖主按钮的缺陷 |
| 鲜果点心与互动小球 | 简洁线条图标、明码价格标签，整卡完成现有兑换与互动操作 |
| 自行车、滑板车、滑板、散步 | 同一尺寸的专属图标与选项卡，试用选中状态和确认操作分开 |
| 穿搭、动作、时长、章节、纪念物 | 统一圆角、间距、触摸尺寸与选中状态；禁用文字和图像更易辨认 |
| 小屋、成长、收藏、故事导航 | 独立线条图标与轻底选中状态，移除文字字符拼接图标 |

正文按钮和文字入口最小触摸高度为 88rpx，在 375px 宽屏上对应 44px；底部导航最小高度为 104rpx。所有按钮采用原生 `hoverClass`，20ms 后显示按压反馈，松开后保留 80ms。选中按钮也具有按压反馈。

图标由原生 View 和 CSS 绘制，复用同一描边与尺寸体系，不依赖特殊字体或新增网络图片。样式限定于宠物中枢，游戏场内操作保持原尺寸。

现有入口 ID、事件、禁用条件和保存逻辑保持不变。每日行动奖励、兑换价格、计时规则、星光币、所选角色和已存装扮没有调整。行动卡取消内嵌小按钮，使用单个整卡 Button，避免嵌套触摸控件。
