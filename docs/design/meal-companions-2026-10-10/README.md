# 饮食社交交互原型

本原型用于确认信息结构和点击流程，使用虚构数据，不连接真实账号、后端、定位或微信服务。它是独立 HTML，不是小程序业务实现。

## 打开

- 本次本地预览：http://127.0.0.1:8767
- 直接用浏览器打开同目录 `prototype.html`，不需要安装依赖。图标字体已嵌入文件，核心交互不依赖网络。侧栏的「原始概念图」链接需同目录 `concept.png`。
- 刷新页面或点击「重置演示」恢复初始数据，关闭后不保留操作。
- 再次启动时，先确认 8767 未被占用，再在本目录运行 `node serve.cjs`。服务器只监听 127.0.0.1，且只提供本原型和概念图。

## 建议体验顺序

1. 找搭子 → 查看约饭 → 申请加入 → 发送申请，查看待确认状态。
2. 点击原型控制区「模拟对方同意申请」（窄屏为「模拟同意」）→ 进入约饭房间 → 发送消息。
3. 晒餐 → 本周榜单 → 用户榜 / 食物榜 → 切换记录、健康、营养素；返回晒餐可点赞、评论。
4. 发起约饭 → 填写标题和条件 → 发布 → 查看详情、管理约饭。
5. 我的约饭 → 初始的「明天午餐，来两个新朋友」→ 管理约饭 → 同意或婉拒小夏。

地点、时间、人数、榜单和营养值全部是演示样本。今天/明天是固定场景标签，不根据真实时间自动到期。成员讨论、通知、取消、举报仅在当前页面模拟。邀请分享和拍照记餐给出衔接说明，不实际发送、拍照或记账。
