# 均衡模式主题效果图

本目录收录均衡模式的八套主题概念效果图。所有主题复用相同的核心信息架构：

- 首页
- 分析
- 圈子
- 我的
- 中央拍照入口
- 功能箱

主题需要同时改变布局、材质、插画、动效和功能箱外观，不能只替换颜色。阴阳、太极和黄色葫芦属于养生模式，不进入均衡模式主题。

| 序号 | 主题 | 主要方向 | 功能箱形态 |
| --- | --- | --- | --- |
| 01 | 澄明秩序 | 编辑式留白、清晰数据、低饱和配色 | 模块化工具抽屉 |
| 02 | 自然共生 | 植物、木石、自然光和有机曲线 | 木质种子匣 |
| 03 | 东方雅集 | 宋画留白、矿物色、漆器和当代东方审美 | 漆木百宝匣 |
| 04 | 现代艺廊 | 抽象构成、画布肌理和策展式排版 | 艺术档案抽屉 |
| 05 | 微缩世界 | 2.5D 场景、微缩地形和探索感 | 旅行背包或场景储物柜 |
| 06 | 绘本陪伴 | 成人绘本、生活叙事和温和陪伴角色 | 帆布陪伴包 |
| 07 | 清朗关怀 | 大字号、大触控区、高可读性和低动效 | 明确标注的工具面板 |
| 08 | 水之道 | 水、岩石、流体构图和现代哲学艺术 | 黑石流体工具舱 |
