# 往期周报归入食探书架

用户需求：之前做的周报，放在书架上。保留木质书架、布面书脊、取书与原有周报阅读场景；首页周报提醒仍暂停。

## 实现

- 书架展示账号已有的全部周报、月报和年报，取消开发预览只显示一本周报的限制。保留原报告 ID、书签和阅读印章。
- 打开书架时，通过实际饮食月历查找最近 12 个已结束的自然周。只有七天数据完整且至少一天有记录，才补入书架。未结束的本周、空周与缺失数据不制造报告。
- “查找更早周报”每次再查 12 周，最多查找此前 60 周；原来已收藏的更早报告仍全部保留。
- 成功打开报告后自动保存其期数元数据。打开失败不保存，保存失败不阻断阅读并提示重试；接口失败保留原收藏。
- 账号或登录状态改变时，停止采用旧请求结果。新增归档沿用原有账号隔离存储键，不存健康数据或凭证。

这里恢复的是报告期数和入口。正文仍由原周报阅读器读取相应日期的现有记录，不是已删除内容或不可变历史快照的恢复。
