# 微信小程序首页双模式 UI V1

更新日期：2026-08-04  
实施分支：`codex/home-modes-v1`

## 目标

首页只保留“养生”和“均衡”两种模式。两套界面共用原有数据、接口、权限和业务动作，只调整功能的呈现位置，不修改营养算法、记录行为或后端数据。

## 两种模式

| 模式 | 定位 | 首页编排 |
|---|---|---|
| 均衡模式 | 保留原首页，适合希望在一个页面连续查看和操作的用户 | 奖励活动、热量与营养、饮食建议、体重/喝水/运动、今日餐食、保质期、饮食统计按旧首页顺序完整展示 |
| 养生模式 | 承接新的低密度养生界面，适合希望分区阅读、减少单屏信息量的用户 | 状态、记录、建议、提醒、伙伴五个页签分区展示，支持点击和横向滑动切换 |

## 交互规则

- 问候区右上角只有一个“养生 / 均衡”切换按钮，不再使用模式选择弹层。
- 切换按钮只展示当前模式名称和“⇄”，不再使用模式前置图标。
- 问候区左侧直接复用原 `PetAvatar` 和真实宠物状态，仅由外层容器提供轻微上下浮动；点击、隐藏设置和宠物小屋等原功能保持不变。
- 点击后立即切换并按账号保存在本机；重新进入首页仍保持上次选择。
- 新用户默认进入均衡模式，优先延续旧首页使用习惯。
- 旧 V1 配置中的养生模式继续保留；旧活力/陪伴模式自动迁移为均衡模式，不产生空白页。
- 明暗主题继续独立工作，不作为第三种模式。

## 功能归属

均衡模式恢复分支基线中的完整旧首页，因此旧功能不会因为双模式改造被删除。养生模式保留已实现的五个功能分区：

1. 状态：热量、宏量/微量营养与目标设置。
2. 记录：体重、喝水、运动与今日餐食。
3. 建议：今天吃什么与饮食统计。
4. 提醒：奖励活动与食物保质期。
5. 伙伴：宠物状态、任务、奖励、成长档案和聊天。

养生模式的活动 Banner 与热量/宏量营养概览固定保留在分区内容上方；切换到记录、建议、提醒或伙伴页时不会消失，保证基础信息和当前活动始终可见。

## V1 边界

- 仅修改微信小程序前端。
- 不新增或修改后端 API、数据库结构或会员门禁。
- 不删除原首页入口和操作。
- 首页模式只本机按账号持久化，暂不云同步。
