# 新拍摄误记历史日期修复（4.6.31）

2026-11-10。代码基线为 dev `9ac11fa5`（4.6.30，包含比例建议、等待互动及连续识别分享修复）。

## 原因与行为

- 底栏相机此前读取 `home_selected_date_v1`。首页显示今天时，该缓存仍可能是浏览过的历史日期，导致新照片被归到旧日。
- 相机/分析准备页保留在后台跨日后，仍可能沿用初始化日期或全局 `recordTargetDate`。
- 现改为：普通新拍照、相册分析默认执行时的今天；只有明确选择补录才携带 `date` 和 `backfill=1`。首页正在浏览历史日期时，拍照/相册入口提供“记录今天 / 补录某日”的明确选择。
- 前台跨午夜、后台恢复、新拍返回、提交和上传完成后均校准普通日期；上传跨午夜时，营养预算与最终提交日一致。
- 历史任务的日期和用户明确补录的日期保留；重新拍摄继续同一历史任务时显式传递该任务日期。超出补录范围时应先在原页重新选择日期。
