# 食堂浏览范围

“美食图谱”是原公共食物库的新名称，地图/列表是展示方式；食堂是其中的场所分类，不是另一套数据。

“校园与社区食堂”默认浏览全部食堂，不要求学校 ID。校园可选择学校、校区、食堂、楼层、窗口；社区·园区包含社区、园区、企业来源。学校偏好只预填校园筛选，不缩小默认全部范围。切换范围保留搜索词，清空下级目录条件，不修改个人档案。

复用 `GET /api/public-food-library`，新增可选 `canteen_scope`：

- `all`：全部已知食堂，以及尚未归类的旧校园标签条目。
- `campus`：实际大学来源或大学目录。
- `community`：社区、园区、企业来源或对应目录。

源采集批次 `venue_type` 优先，其次学校目录 `location_type`。不按名称猜学校，不把社区伪造为大学，不仅按旧 `type=campus` 筛选：历史导入可能同时包含 `common` 与 `campus`。普通餐馆不因新范围成为食堂。

范围请求返回 `canteen_scope` 回执、派生的条目 `venue_type`；未带参数的旧请求不变。派生字段不写库、不参与迁移，原发布状态、营养可记录限制和双向屏蔽仍生效。图谱食堂标签使用同一范围接口；来源未知仅标“食堂”。

前端检查范围回执，防止旧服务忽略新参数后把普通餐馆误显示为食堂。该改动需要后端接口与微信包一起发布；修改本地代码不等于手机体验版生效。AI 原点数据位置已由独立任务更新，本改动不重复改定位、价格、营养或推荐权重。
