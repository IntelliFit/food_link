## 线上食物识别碳水为 0 修复

- Task: 用户反馈线上版本食物识别中很多食物碳水显示为 0g（猪头肉、酱牛肉、红烧牛肉面等）。
- Status: fixed_static_verified_restart_required
- Root cause:
  - `backend/internal/analyze/service/deepseek_nutrition.go` 的 `nutritionKeyAliases` 遗漏了 `carbs` 字段的别名映射。
  - 当 DeepSeek 模型返回 `carbohydrate` 或 `carbohydrates` 而非 `carbs` 时，`coerceExtendedNutrients` 无法正确提取碳水值，`numberFromAny(nil)` 返回 0，导致 fallback 生成的单位营养中碳水为 0。
  - 这影响所有未命中食物库、走 DeepSeek fallback 的食物。
  - 此外 `backend/internal/foodrecord/domain/food_record_domain.go` 的 `FoodItemNutrients.UnmarshalJSON` 也缺少碳水别名兼容，影响外部数据导入/历史记录反序列化场景。
- Change:
  - `backend/internal/analyze/service/deepseek_nutrition.go`: `nutritionKeyAliases` 全面补充宏量营养素别名：
    - `calories`: `{"calories", "calorie", "kcal", "energy", "total_calories"}`
    - `protein`: `{"protein", "total_protein"}`
    - `carbs`: `{"carbs", "carbohydrates", "carbohydrate", "total_carbs"}`
    - `fat`: `{"fat", "total_fat"}`
    - `fiber`: `{"fiber", "dietary_fiber", "fibre"}`
    - `sugar`: `{"sugar", "total_sugar", "sugars"}`
  - `backend/internal/foodrecord/domain/food_record_domain.go`: `FoodItemNutrients.UnmarshalJSON` 的 `aux` 结构体新增：
    - `CarbsSnake`（`carbohydrate`）、`CarbsPluralSnake`（`carbohydrates`）
    - `FiberSnake`（`dietary_fiber`）、`FibreSnake`（`fibre`）
    - `SugarSnake`（`total_sugar`）、`SugarsSnake`（`sugars`）
    并在反序列化后赋值。
  - `backend/internal/analyze/service/deepseek_nutrition_test.go`: 新增 `TestDeepSeekNutritionEstimator_EstimateParsesCarbohydrateAlias`、`TestDeepSeekNutritionEstimator_EstimateParsesCarbohydratesPluralAlias`、`TestDeepSeekNutritionEstimator_EstimateParsesAllMacroAliases` 回归测试。

## 酱牛肉仍显示碳水 0 的数据库根因与修复

- Task: 用户再次实测后发现 `酱牛肉` 仍显示碳水 0g，要求检测当前数据库中哪些数据有问题并纠正。
- Finding:
  - 当前远程库 `food_nutrition_library` 中标准食物 `酱牛肉` 本身不是 0：
    - `id=2efcbcce-069e-4abb-b93b-dce5c70ae7ff`
