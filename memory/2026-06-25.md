## 小程序首页白屏 useState 运行时修复
- 用户反馈微信开发者工具首页白屏，console 报 `TypeError: Cannot read property 'useState' of undefined`，栈位于 `pages/index/index.js` 的 `IndexPage`。
- 定位结论：不是后端数据/权限问题，首页函数在请求前的 React hook 阶段就崩溃；当前首页使用 `import { useState, useEffect, useCallback, useRef, useMemo } from 'react'`，dist 中 `IndexPage` hook 被编译成运行时敏感的 hook 访问形态。项目 2026-03-27 已记录同类 Taro hook 绑定问题，首页应使用 `React.useState/useEffect/useCallback` namespace 写法。
- 已修复 `apps/wechat/src/pages/index/index.tsx`：改为 `import React from 'react'`，首页 hooks 统一 `React.use*`，`Taro.useDidShow` 改为命名导入 `useDidShow`。
