## 2026-06-14 修复 Admin 举报列表为空

### 根因
`backend/internal/admin/repo/feed_report_repo.go` 中的 `ListFeedReportResult` 结构体没有 JSON tag：

type ListFeedReportResult struct {

### 修复
添加 JSON tag：
```go
type ListFeedReportResult struct {
    Items []admindomain.FeedReportItem `json:"items"`
    Total int64                        `json:"total"`
}
```

## 2026-06-14 飞书举报卡片增加复制 ID 按钮

### 需求
用户在飞书举报卡片「去处理」按钮后增加三个按钮，分别复制：
- 举报人 ID
- 被举报人 ID
- 动态 ID

### 调研结论
飞书消息卡片的 `button` 组件没有原生「复制到剪贴板」能力；自定义机器人 webhook 也无法处理按钮回调。`button` 仅支持：
- `open_url` / `url`：跳转链接
- `callback` + `value`：回传事件（需要应用回调地址）
- `form_submit`：提交表单

因此，按钮本身不能直接复制文本。

### 实现方案
采用「按钮跳转 + Admin 详情页自动复制」：
- 三个复制按钮均为 URL 按钮，点击后打开 Admin 详情页并带上 `?copy=reporter|reported|target`。
- Admin 详情页加载数据后，读取 URL 参数并调用 `navigator.clipboard.writeText` 自动复制对应 ID，同时 Toast 提示。
- 为避免自动复制受浏览器权限限制失败，详情页中举报人、被举报人、被举报对象 ID 旁均增加手动复制按钮。

### 代码变更
- `backend/internal/community/service/report_notifier.go`：
  - 将原来的单个「去处理」按钮扩展为一组按钮，新增「复制举报人ID」「复制被举报人ID」「复制动态ID」。
  - 复制按钮 URL 为 `{adminBaseURL}/feed-reports/{reportId}?copy={type}`。
- `admin/src/pages/feed-report-detail-page.tsx`：
  - 引入 `useSearchParams` 与 `Copy` 图标。
  - 新增 `copyText` 通用复制函数。
  - 数据加载完成后根据 `copy` 参数自动复制对应 ID，并清理 URL 参数。

  - `UserInfo` 新增复制按钮，分别复制举报人/被举报人 ID。

4. 侧边栏按钮对齐问题根因：`admin/src/styles.css` 全局定义 `button { justify-content: center; }`，覆盖了 Tailwind `justify-start`，导致按钮内容水平居中。

### 修复方案
1. **举报管理页布局**：将页面根容器改为 `grid grid-cols-[256px_minmax(0,1fr)] gap-8`，与 `benchmark-page.tsx`、`feedback-page.tsx` 保持一致。
2. **侧边栏按钮左对齐**：在 `admin-sidebar.tsx` 的导航按钮上增加 `!justify-start` 与内联 `style={{ justifyContent: 'flex-start', textAlign: 'left' }}`，强制覆盖全局 button 居中样式。
3. **统一 8 栅格**：侧边栏宽度 256px，grid 间距 gap-8（32px），导航按钮间距 gap-3（12px），内边距 px-5（20px）/ py-4（16px），分隔线 my-8（32px）。
