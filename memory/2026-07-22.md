## 健康档案入口持续加载

- 用户反馈注册时未填全健康信息，注册完成后从「我的」点击“完善健康档案”只显示 spinner，无法进入。
- 生产只读核查排除数据和后端接口卡死：截图时段三个 main 容器无该接口慢请求/5xx；疑似账号的健康档案与用户资料 GET 实测均为 200，分别约 626ms 和 115ms。
- 页面结束 loading 后原本一次挂载 13 个步骤，其中隐藏体重尺会创建 1701 个刻度、约 3500 个原生节点；真机提交新树时可能卡住并保留 spinner。注册头像昵称后的进入和“完善健康档案”点击均落到同一页面，所以是同一故障。
- 已改为只挂载当前步骤，其他步骤只保留轻量占位，并取消整页滑动动画；两个读取 GET 设 10 秒超时、用户资料/健康档案保存设 15 秒超时，增加加载失败页和重试按钮。
- TypeScript、定向 ESLint、Jest 17 suites / 64 tests、diff check 通过。微信开发者工具 9420 运行时验证：直接进入及“我的→完善健康档案”实际点击后均无 spinner、问卷标题存在、隐藏体重尺不存在、控制台 0 error。截图命令超时；Mock API 不受当前 DevTools 版本支持，为避免写用户档案未实际点击会保存草稿的“下一步”。尚未上传小程序版本。

- 当前开发后端日志证明现有会员的体验版请求被 409“会员已开通”拦截；这是上一版新增判断导致的回归，不是微信支付接口没有收到请求。
