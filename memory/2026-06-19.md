- 已修复：
  - `backend/internal/analyze/service/llm_client.go` 增加 `AnalyzeWithImagesAndTemperatureModel`，支持单次调用覆盖模型名。

  - `apps/wechat/src/utils/api.ts` 专线 timeout 调整为 125s，并移除认证请求开始/完成的 debug console。
