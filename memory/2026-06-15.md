# 2026-06-15

## 完成：修复 Mobile Metro 无法解析 react

- 用户在 Expo Go 中看到红屏：`Unable to resolve "react" from "apps/mobile/src/providers/AuthProvider.tsx"`；终端显示 Android Bundling 500。
- 根因：为规避 monorepo 中小程序 React 18 与 mobile React 19 的类型冲突，曾在 `apps/mobile/tsconfig.json` 的 `paths` 中把 `react`、`react/jsx-runtime` 指向 `./node_modules/@types/react`。Expo/Metro 会读取该 `paths`，导致运行时把 `react` 解析到类型包，进而无法打包。
- 修复：
  - 从 `apps/mobile/tsconfig.json` 移除 `react` / `react/jsx-runtime` / `react/jsx-dev-runtime` 的运行时 paths。
  - 新增 `apps/mobile/tsconfig.typecheck.json`，只在 `tsc` typecheck 时使用 `@types/react` paths。
  - `apps/mobile/package.json` 的 `typecheck` 脚本改为 `tsc --project tsconfig.typecheck.json --noEmit --pretty false`。
- 验证：`npm --workspace apps/mobile run typecheck` 通过；`ReadLints` 未发现新增诊断。
- 运行提示：正在运行的 Metro 可能仍缓存旧解析结果，需要在 Expo 终端按 `r` reload；若仍显示旧错误，停止当前 Expo 后重新运行 `npm --workspace apps/mobile run start -- --lan --clear`。
