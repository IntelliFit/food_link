## Food analysis correction calorie rescale

## 组合装零食多列营养表入库修复
- User feedback: large packaged snacks with two or more foods/flavors in one package could not be submitted to the snack library. Feedback task example was `迷你梦龙浓郁黑巧克力冰淇淋、松露巧克力口味冰淇淋组合装`, user `6f0b67e5-f3b1-4b38-b3fc-081d931d8ef1`, created `2026-06-08 20:21`.

The prompt now explicitly asks models to preserve multi-column labels in `raw_label_payload`.
- Mini-program task detail now derives the same weighted nutrition from historical `raw_label_payload` when `unit_nutrition_per_100g` is zero, so old blocked tasks can prefill the supplement form instead of requiring manual nutrition math.
