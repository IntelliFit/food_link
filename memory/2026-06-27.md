## 官网饮食记录分享页移动端二次优化

### 需求
- 用户提供手机浏览器截图，反馈饮食记录分享页元素间距奇怪，底部操作区过重。
- 要求底部只保留绿色「App 内打开」按钮，不要复制按钮，也不要外层白色框。

### 修改
- `website/src/pages/FoodRecordSharePage.tsx`
  - 移动端主内容收窄为 `max-w-[440px]`，顶部与卡片间距收敛。
  - 标题、描述、食物明细区的移动端字号、行高、内边距略缩小。
  - 移除复制按钮、复制 toast 和底部白色胶囊容器。
  - 底部悬浮区改为单个居中的绿色「App 内打开」按钮，保留原有 Android intent / iOS scheme 打开逻辑。

### 验证
- `cd website && npm run build` 通过。
- `cd website && npx eslint src/pages/FoodRecordSharePage.tsx` 通过。
- `git diff --check` 通过，仅有 LF/CRLF 工作区换行提示。

### 后续
- 推送后等待官网部署，再用手机浏览器实测分享页按钮位置、间距和 App 拉起行为。

## 官网分享页营养指标布局修正

### 需求
- 用户反馈分享页营养指标区域的 `kcal`、`g` 字体和布局仍然奇怪，移动端只看到单位，数字被挤掉。

### 修改
- `website/src/pages/FoodRecordSharePage.tsx`
  - 营养指标区从移动端 4 列窄竖卡改为 2x2 横向卡片，桌面端仍保持 4 列。
  - `Metric` 组件改为左侧图标/指标名、右侧数值/单位的横向布局。
  - 移除数值上的 `truncate`，并让数值单位 `whitespace-nowrap`，避免窄屏下只显示 `kcal` / `g`。

### 验证
- `cd website && npm run build` 通过。
- `cd website && npx eslint src/pages/FoodRecordSharePage.tsx` 通过。
- `git diff --check` 通过，仅有 LF/CRLF 工作区换行提示。
