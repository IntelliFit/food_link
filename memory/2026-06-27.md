## 官网分享页悬浮按钮微信内置浏览器居中修正

### 需求
- 用户反馈底部悬浮「App 内打开」按钮在 Via 浏览器正常，但微信内置浏览器里不居中；同时希望按钮整体往上移动约 20px。

### 原因
- 原实现中按钮自身使用 `mx-auto inline-flex w-full max-w-72` 居中。部分浏览器能正常处理，但微信内置浏览器/X5 内核对 `inline-flex` 和 auto margin 的组合表现不稳定，可能导致横向偏移。

### 修改
- `website/src/pages/FoodRecordSharePage.tsx`
  - 固定底部容器改为 `flex justify-center`，由外层负责稳定居中。
  - 按钮从 `inline-flex` 改为普通 `flex`，避免微信内置浏览器居中偏差。
  - 底部 padding 从 `1.05rem` 调整为 `2.3rem`，按钮整体约上移 20px，并继续兼容 `safe-area-inset-bottom`。

### 验证
- `cd website && npm run build` 通过。
- `cd website && npx eslint src/pages/FoodRecordSharePage.tsx` 通过。
- `git diff --check` 通过，仅有 LF/CRLF 工作区换行提示。
