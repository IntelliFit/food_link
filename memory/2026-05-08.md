## User metrics snapshot

- User asked for recent 7-day active users, successful paid users, and whether the ratio is meaningful.
- Read-only production Supabase check used the local China-time window `2026-05-02 00:00:00` to current time on `2026-05-08`.
- Working active-user definition:
  - distinct users appearing in any of:
    - `analysis_tasks.created_at`
    - `user_food_records.record_time`
    - `user_exercise_logs.recorded_on`
- Working successful-paid definition:
  - distinct users with at least one `pro_membership_payment_records.status='paid'`
- Result snapshot:
  - 7-day active core users: `35`
  - ever successful paid membership users: `12`
  - paid users active in the same 7-day window: `7`
  - current paid-like membership snapshots: `13`
- Interpretation:
  - `12 / 35 = 34.3%` is usable as paid penetration among recent active users, but not as a retention metric because it mixes a 7-day numerator/denominator with cumulative payment history.
  - `7 / 12 = 58.3%` is the more meaningful rough indicator for “付费用户最近 7 天是否还在用”.
  - Snapshot-based current membership counts are less trustworthy for “成功付费人数” because there are active paid-like snapshots without matching paid membership order rows.
