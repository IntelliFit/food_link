# 2026-07-29

## AI 饮食项链方向复核

- 用户纠正前一轮“磁吸领扣/胸针优先”的建议：多数用户没有佩戴胸针或磁吸领扣的习惯，设备需要随衣服更换、重新安装且存在掉落风险；用户当前更认可项链，并要求按佩戴习惯重新调研。
- 重新调研后，当前工作假设调整为“项链是最合理的单一主载体”。真实颈戴饮食传感研究对日常活动和公共场景的接受度提供了初步支持；现有 AI 随身设备也反复选择吊坠形态。
- 项链的工程重点不是改成领夹，而是解决前端吊坠方向：双点悬挂、后置电池/配重、低重心扁平机身、可调但受限的链长、IMU 判断稳定窗口后选帧。
- 仍需真人验证，尤其是男性/女性不同审美、夏冬服装遮挡、中式多人共餐、运动时摆动、整日佩戴时长和公开场景隐私接受度。

## RAG / embedding / rerank 代码核验

- 当前 `dev` 已实现营养库 embedding 召回：可信名称向量持久化到 `food_nutrition_embeddings`，运行时精确余弦检索，与词法候选做 RRF 融合后取 Top 5。
- embedding 功能默认关闭，是否在线上启用由 Apollo/环境的 `nutrition_embedding_enabled`、API Key、模型及维度决定；本地仅能确认代码接入，无法确认线上开关。
- 候选后处理使用普通 LLM 进行严格食物身份门禁，代码名为 semantic rerank；默认优先 Qwen 3.6 Flash、回退 DeepSeek，不是独立 reranker 模型。
- 没有发现通用私有文档知识库问答式 RAG；营养匹配属于检索增强候选决策，此外食物识别模式还支持模型原生 web search。
