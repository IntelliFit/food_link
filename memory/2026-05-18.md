- 用户要求在当前目录 `AGENTS.md` 增加后端数据库修改约束：修改数据库结构时禁止手动执行 SQL 作为最终方案，应先编辑对应 Go 数据模型，再运行 `cmd` 下的迁移命令。
- 已新增“后端数据库结构变更”小节：先修改 `backend/internal/migration/do/schema_do.go` 迁移 DO；必要时同步 domain/repo/service/DTO；AutoMigrate 不可靠或需稳定命名的约束、索引、check、外键、触发器等写入 `backend/internal/migration/migration.go` 的幂等迁移逻辑。
- 固定执行口径：从 `backend/` 运行 `go run ./cmd/migration -config-dir .`；执行前必须确认 `backend/config.yaml` 与环境变量实际指向的数据库，非本地或不确定目标库需先获得用户明确确认。只读 SQL 可用于诊断，修复性 SQL 必须落回迁移代码。
