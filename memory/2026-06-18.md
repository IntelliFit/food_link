## 2026-06-18 Mobile Android 发布方式咨询

- 建议方向：如果要摆脱 EAS 队列，先配置 Android release keystore 和 Gradle release signing，再用本地 Gradle/Expo 构建 APK，最后复用 `npm run release:mobile:android -- --artifact-apk <apk-path>` 只做 COS 上传和 channel manifest 更新。
