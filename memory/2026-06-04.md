- 已修改主链路包装食品处理：

  - 支持 key：`require_done`、`require_mixed`、`min_items`、`min_packaged`、`min_non_packaged`、`min_ai_fallback`、`max_unresolved`、`max_missing_nutrition`、`require_ai_ratio`、`require_package_anchor`。
  - `require_mixed` 会自动展开为至少 `2` 个 item、至少 `1` 个包装 item、至少 `1` 个非包装 item。
  - `--expect` 可与全局 gate 合并；若 case 名称不存在，启动前直接报错。
- 继续补充语义 gate：
  - `name_contains=<文本>`：任意 item 名称或 food id 需要包含该文本。
  - `packaged_name_contains=<文本>`：包装 item 需要包含该文本。
  - `non_packaged_name_contains=<文本>`：非包装 item 需要包含该文本。
  - 用于避免真实混合图只满足“数量上有包装+普通”，但包装项不是目标商品或普通餐饮主体被漏掉。

  - 混合图：`--expect mixed:require_done,require_mixed,require_ai_ratio,require_package_anchor,packaged_name_contains=雀巢,non_packaged_name_contains=炸猪排,max_unresolved=0,max_missing_nutrition=0`
