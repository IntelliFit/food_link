# 2026-05-15

## 新增：微信小程序端到端自动化测试系统（Phase 1 MVP）

用户要求利用 weapp-devtools skill 结合现有 Go E2E 测试数据库，构建一套微信小程序自动化测试系统。

### 已交付

1. **Go Test Server** (`backend/e2e-test/cmd/api-test-server/main.go`)
   - 复用现有 E2E PrepareDatabase、ApplySeedSQL、app.New 机制
   - 启动真实 HTTP server（默认 :3010），供小程序调用
   - 注册测试专用路由（仅 Env=test）：
     - GET /api/test/health — 健康检查
     - GET /api/test/auth/token?user=user1 — 签发测试用户 JWT
     - POST /api/test/db/query — 只读 SQL 查询（跨层断言）
     - POST /api/test/db/reset — 重置数据库到 fixture 状态
     - GET /api/test/suite/vars — 获取 suite 变量
   - 为支持外部调用，将 suiteVars() 导出为 SuiteVars()

2. **e2e-weapp Node.js 项目**
   - e2e-weapp/package.json — 独立 Node.js 项目
   - e2e-weapp/tsconfig.json — TypeScript 配置
   - e2e-weapp/src/types.ts — 场景/步骤/结果类型定义
   - e2e-weapp/src/mrc.ts — mrc CLI 封装层
   - e2e-weapp/src/backend-client.ts — Go Test Server HTTP 客户端
   - e2e-weapp/src/runner.ts — 主运行器
   - e2e-weapp/scenarios/home-dashboard.yaml — 第一个测试场景

3. **根级集成**
   - package.json 新增 "test:e2e-weapp": "cd e2e-weapp && npx ts-node src/runner.ts ..."

### 端到端验证结果

手动执行完整链路验证成功：
1. Go Test Server 启动，创建临时 PostgreSQL 数据库
2. /api/test/health 返回正常
3. /api/test/auth/token 成功签发 JWT
4. mrc evaluate 注入 token 到小程序 storage
5. mrc relaunch 重启到首页
6. mrc wait + mrc screenshot 成功生成截图（319KB PNG，780x1688px）
7. 截图显示小程序首页正确渲染（卡路里卡片、日期选择器、TabBar 等）

### 使用方式

```bash
# 1. 确保 PostgreSQL 运行、微信开发者工具已启动自动化
# 2. 运行测试
npm run test:e2e-weapp

# 或使用环境变量覆盖数据库配置
DATABASE_HOST=127.0.0.1 DATABASE_USER=kirigaya npm run test:e2e-weapp
```

### 限制

- 截图中首页数据（体重/喝水/运动）显示为默认值而非 fixture 数据，因为 fixture 数据日期为 2026-05-14，而小程序默认请求当天（2026-05-15）的数据。后续场景可通过 URL 参数指定日期或调整 fixture。
- 微信开发者工具需在 GUI 中手动开启自动化服务（工具 → 自动化），或使用 cli auto 命令启动。
- mrc 每次命令 stateless，场景步骤多时会累积延迟。
